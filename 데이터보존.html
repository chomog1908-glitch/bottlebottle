BOTTLEBOTTLE · v0.2.1

데이터 보존 구조

앱을 업데이트해도 어머니의 기록이 남는 이유. 네 겹으로 되어 있고, 각 겹은 앞 겹이 무너졌을 때를 위한 것이다.

01 안드로이드가 지켜주는 것

APK를 덮어 설치하면 안드로이드가 앱 데이터 폴더를 그대로 둔다. 단, 세 가지가 맞아야 한다.

항목값어긋나면
패키지 이름com.bottlebottle.bottlebottle완전히 다른 앱으로 깔린다
서명 열쇠CN=BottleBottle덮어쓰기를 거부한다
versionCode2 → 3내려가면 설치를 거부한다
열쇠를 잃어버리면 복구할 수 없다

열쇠는 keystore/bottlebottle-release.jks 와 android/key.properties. 둘 다 .gitignore 에 있어 공개 저장소로 나가지 않는다. 다른 열쇠로 서명하면 영영 덮어 설치가 안 되고, 지우고 새로 깔아야 하며, 그러면 기록이 통째로 사라진다.

데이터가 날아가는 경우는 넷뿐이다.

  • 1앱을 지우고 다시 설치
  • 2설정에서 앱 데이터 삭제
  • 3패키지 이름 변경
  • 4서명 열쇠 변경
flutter install 을 쓰지 말 것

이 명령은 기존 앱을 지우고 깐다. 실제로 그렇게 해서 실기기의 진행도를 한 번 날렸다. 올바른 명령은 adb install -r 이고, 파일을 직접 옮겨 설치해도 된다.

설치 화면에 “기존 앱을 지우고 설치” 가 뜨면 누르지 않는다. 그냥 설치 또는 업데이트.

02 앱이 담는 방식

SharedPreferences에 열쇠 열 개로 나눠 담는다. 이름 끝의 _v1 은 형식이 바뀔 때 올릴 자리다.

saved_game_v1          지금 두던 판 (레벨 + 수순 + 시작 보드)
max_level_v1           도달한 최고 레벨
cleared_levels_v1      클리어한 레벨 번호 목록
play_stats_v1          누적 기록 (13,951수 · 19일 · 되돌리기 1,119회…)
achievement_dates_v1   도전과제를 딴 날짜 (= 얻은 것 목록)
seen_rule_notes_v1     이미 본 규칙 안내

show_symbols_v1        색약 모드
sound_on_v1            소리
large_text_v1          큰 글씨
theme_mode_v1          밝게 / 어둡게

도전과제는 계산과 저장을 겹쳐서 본다. play_stats_v1 로 계산한 결과 또는 achievement_dates_v1 에 날짜가 적힌 것. 둘 중 하나면 얻은 것이다.

계산만 쓰면 편하다 — 통계와 도전과제가 따로 놀 방법이 없다. 하지만 나중에 목표를 손대는 순간(예: “50판”을 “60판”으로) 이미 드린 도전과제가 조용히 취소된다. 날짜는 남아 있는데 배지만 꺼진다. 427판을 푸시며 모으신 것을 내 사정으로 도로 가져가는 셈이다.

그래서 합집합으로 본다. 목표를 낮추면 새로 얻고, 올려도 이미 얻은 것은 남는다. 날짜 지도가 곧 “얻은 것 목록”이므로 따로 목록을 두지 않는다 — 두 곳에 적으면 언젠가 서로 어긋난다.

클리어 기록은 그냥 번호 목록이다. ["428","429","430"]. 판이 어떻게 생겼든 상관없으므로, 아래 03에서 판이 바뀌었을 때도 이것만은 무사했다.

03 판이 바뀌어도 견디게

여기가 실제로 한 번 깨진 곳이다.

예전 방식은 레벨 431 + 둔 수 43개 만 저장했다. 앱을 켜면 431 판을 다시 만들어 그 위에 43수를 재생한다. 레벨 생성이 결정적이라 번호만 알면 같은 판이 나오기 때문이다. 저장이 아주 작아지는 영리한 방법이었다.

그 결정성을 깨는 사람이 나였다

레벨 432가 열리지 않던 것을 고치면서 셔플이 난수를 한 번 더 뽑게 되었다. 그 한 번이 난수 흐름을 밀어 레벨 1~700 중 699개의 판이 바뀌었다. 저장된 43수는 첫 수부터 재생되지 않았다.

지금은 시작 보드도 함께 저장한다. 판을 다시 만들 필요가 없으니 생성기를 고쳐도 깨지지 않는다. 몇 KB 더 든다.

“지금” 보드가 아니라 “시작” 보드를 담는다. 수순을 시작 보드 위에 다시 두어야 되돌리기 기록이 함께 살아난다. 지금 보드만 저장하면 보드와 되돌리기가 따로 놀아, 복원한 뒤 되돌리기를 누르면 엉뚱한 데로 간다. PLAN에 “내용물을 저장하면 되돌리기가 깨진다”고 적어 둔 우려가 이것이고, 둘 다 저장하면 해결된다.

예전 저장에는 보드가 없다. 그때는 예전처럼 레벨 번호로 만든다 — 어머니 폰에 지금 들어 있는 저장이 이 경우다. 보드가 규격에 맞지 않으면 조용히 무시하고 생성된 판으로 연다. 저장이 손상돼도 게임은 켜져야 한다.

04 비상용 — 내보내기

설정 화면의 기록 내보내기. 위 열쇠 전부를 글자 하나로 뽑아 클립보드에 넣는다.

{"app":"bottlebottle","format":1,
 "exportedAt":"2026-09-07T20:00:42",
 "data":{ …열쇠 열 개 전부… }}

폰을 바꿀 때 옮길 유일한 수단이고, 위 세 겹이 모두 실패해도 이것은 남는다. 불러오기는 읽을 수 있을 때만 덮어쓴다 — 형식이 아니거나 값이 이상하면 아무것도 건드리지 않는다. 잘못 붙여넣은 글자 때문에 지금 기록이 날아가는 것이 이 기능으로 일어날 수 있는 최악이기 때문이다.

권장

가끔 한 번씩 뽑아 두면 안전하다. 의존성은 늘지 않았다.

— 이번 업데이트의 결산

클리어한 레벨 427판남음
도전과제 24개남음
누적 기록 13,951수 · 19일남음
최고 레벨 431남음
431번 두시던 판의 43수잃음

잃은 것은 붙잡고 계시던 한 판뿐이다. 이미 푸신 427판을 다시 푸실 필요는 없다.

앞으로

어머니 폰에서 실제로 뽑은 기록을 시험에 넣어 두었다. 저장 형식을 건드릴 때 이미 쌓인 기록이 깨지면 곧바로 잡힌다. 지어낸 자료로는 알 수 없는 것이다.
